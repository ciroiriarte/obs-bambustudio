# Purpose
* Native packages of Bambu Studio (https://github.com/bambulab/BambuStudio) for
  Linux distributions, built from upstream source on OBS
  (https://build.opensuse.org), installable with zypper/dnf/apt.
* Autonomous pipeline: new upstream **stable** releases are detected by
  `.github/workflows/upstream-bump.yml` and rebuilt on OBS without manual work.

# Scope
## Distributions
* Primary: openSUSE Slowroll (x86_64 only on OBS).
* Later, once Slowroll is green: openSUSE Tumbleweed/Leap 16.0, Rocky Linux 9/10,
  Ubuntu LTS, Debian stable. Debian/Ubuntu need `debian.*` recipe files.

## Packages
* `bambustudio-deps`: build-only, publish disabled. Upstream's `deps/` superbuild
  built offline into `/opt/bambustudio-deps`. Source list is GENERATED by
  `tools/gen_deps.py` — never hand-edit the block between the BEGIN/END markers;
  change `%deps_cmake_flags` and re-run the generator instead.
* `bambustudio`: the published package, static-linked against bambustudio-deps.

# Rules
* OBS builds have no network: every input must be a `Source:` in the spec.
* No patent-encumbered or EOL bundled components on OBS: FFmpeg and OpenSSL come
  from the distribution.
* Keep README.md current with anything a user or maintainer needs.
