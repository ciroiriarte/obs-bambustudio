# Purpose
* Native packages of Bambu Studio (https://github.com/bambulab/BambuStudio) for
  Linux distributions, built from upstream source on OBS
  (https://build.opensuse.org), installable with zypper/dnf/apt.
* Autonomous pipeline: new upstream **stable** releases are detected by
  `.github/workflows/upstream-bump.yml` and rebuilt on OBS without manual work.

# Scope
## Distributions
* Primary: openSUSE Slowroll (x86_64 only on OBS).
* Later, once Slowroll is green: openSUSE Tumbleweed/Leap 16.0, Rocky Linux 9/10,
  Ubuntu LTS, Debian stable. Debian/Ubuntu need `debian.*` recipe files.

## Packages
* `bambustudio` (single OBS package). Dependency policy: distribution libraries
  wherever compatible; only the bambulab wxWidgets fork, Boost, TBB, OCCT, CGAL,
  OpenVDB (+Blosc, OpenEXR) and libnoise are built from upstream's `deps/`
  superbuild as static archives in the build tree, linked in, never installed.
* The bundled Source list is GENERATED by `tools/gen_deps.py` from the spec's
  `%deps_cmake_flags` / `%deps_targets` — never hand-edit the block between the
  BEGIN/END markers; change those globals and re-run the generator.
* To unbundle a library for a distro: add its DEP_BUILD_*=OFF / drop its target,
  add the system BuildRequires, re-run the generator.

# Rules
* OBS builds have no network: every input must be a `Source:` in the spec.
* No patent-encumbered or EOL bundled components on OBS: FFmpeg, OpenSSL, curl,
  image libraries etc. come from the distribution.
* Bundled libraries must stay private: %check fails if bambu-studio links or
  exports them (link uses -Wl,--exclude-libs,ALL).
* Keep README.md current with anything a user or maintainer needs.
